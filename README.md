# chinacjf-admin

> 帮助你快速实现一个系统。

## 功能介绍

- 角色管理
- 日志管理
- 菜单管理
- 用户管理
- 字典管理
- 暗色主题适配切换
- 现支持2种布局方式，未来会支持更多常用的布局已经在规划中～
- 支持适配主题色、色弱模式、灰色模式
- 支持4种路由过渡动画
- 支持国际化，内涵轻松适配各种语言的方案
- 支持权限控制
- 支持路由缓存
- 支持菜单外链、内嵌自定义
- 支持两种标签栏定制
